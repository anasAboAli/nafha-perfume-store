# خطة التنفيذ — متجر نفحة

القرارات الأساسية:
- **القالب:** Blocksy مع Child Theme (`nafha-child`). خفيف، دعم RTL ممتاز، ومتوافق مع WooCommerce والمحرر.
- **بناء الصفحات:** محرر الكتل (Gutenberg) بدل Elementor للحفاظ على السرعة.
- **الكود المخصص:** إضافة `nafha-core`، وكل ميزة في وحدة مستقلة داخل `includes/`.
- **مبدأ الإضافات:** ما يمكن بناؤه بكود خفيف (واتساب، السلة الجانبية، شريط الشحن المجاني، الاختبار، أحداث التتبع) يُبنى في `nafha-core` لتقليل عدد الإضافات.
- **العملة:** دولار أمريكي (USD). واتساب المتجر: 970598143863.
