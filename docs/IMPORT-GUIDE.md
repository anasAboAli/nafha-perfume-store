# دليل استيراد المنتجات بالجملة (CSV)

الملف النموذجي: [products-import-sample.csv](products-import-sample.csv) — افتحه في Excel أو Google Sheets، أضف منتجاتك بنفس الشكل، ثم احفظه بصيغة **CSV UTF-8**.

## خطوات الاستيراد
1. لوحة التحكم ← **المنتجات** ← **استيراد**.
2. اختر الملف، ولا تفعّل "تحديث المنتجات الموجودة" إلا إذا كنت تعدّل منتجات موجودة (بنفس الـ SKU).
3. في شاشة ربط الأعمدة ستُربط الأعمدة تلقائيًا (بما فيها **العلامات التجارية** وحقول **ملف العطر**). اضغط **تشغيل المستورد**.

## كيف يُكتب العطر المتعدد الأحجام
كل عطر = **صف رئيسي** (`variable`) + **صف لكل حجم** (`variation`):

| العمود | الصف الرئيسي | صفوف الأحجام |
|---|---|---|
| Type | `variable` | `variation` |
| SKU | رمز فريد، مثل `dior-sauvage-edp` | رمز لكل حجم، مثل `dior-sauvage-edp-5ml` |
| Parent | فارغ | SKU الصف الرئيسي |
| Name، الأوصاف، Categories، Brands | تُملأ | فارغة |
| Regular price، Stock | فارغة | سعر ومخزون هذا الحجم |
| Attribute 1 name | `size` | `size` |
| Attribute 1 value(s) | كل الأحجام: `5 مل, 10 مل, 30 مل, العبوة الكاملة` | حجم واحد: `10 مل` |
| Attribute 1 default | الحجم المختار افتراضيًا | فارغ |
| Visibility in catalog | `visible` | `visible` |

العبوة الكاملة أو الإكسسوار بسعر واحد: صف واحد بنوع `simple` مع السعر والمخزون.

## الخصائص (Attributes 2–6)
اكتب **الاسم كما يظهر في الموقع بالعربية** (وليس الاسم الإنجليزي) وافصل بين القيم بفاصلة إنجليزية `,`:

| Attribute name | القيم المتاحة |
|---|---|
| `fragrance-family` | خشبي، زهري، شرقي، حمضي، فريش، عنبري، مسكي |
| `season` | صيف، شتاء، ربيع، خريف، كل المواسم |
| `occasion` | يومي، العمل، السهرات، المناسبات الخاصة |
| `gender` | رجالي، نسائي، للجنسين |
| `concentration` | بارفان (Parfum)، أو دو بارفان (EDP)، أو دو تواليت (EDT) |
| `size` | 5 مل، 10 مل، 30 مل، العبوة الكاملة |

> ⚠️ أي قيمة مكتوبة بشكل مختلف (مثلًا `fresh` بدل `فريش`) ستُنشئ قيمة جديدة مكررة في الفلاتر.

## ملف العطر
| العمود | المحتوى |
|---|---|
| `Meta: _nafha_name_en` | الاسم الإنجليزي (يظهر تحت العنوان ويُستخدم في البحث) |
| `Meta: _nafha_notes_top` / `_heart` / `_base` | النوتات، مفصولة بفاصلة عربية `،` |
| `Meta: _nafha_longevity` | الثبات من 1 إلى 5 |
| `Meta: _nafha_sillage` | الانتشار من 1 إلى 5 |

## الصور والتصنيفات والعلامات
- **Images**: رابط كامل لصورة (أو عدة روابط مفصولة بفاصلة؛ الأولى هي الرئيسية). ارفع الصور أولًا إلى مكتبة الوسائط وانسخ روابطها.
- **Categories**: اسم التصنيف كما في الموقع، مثل `عطور رجالية` (عدة تصنيفات تُفصل بفاصلة).
- **Brands**: اسم العلامة كما في الموقع، مثل `Dior`. العلامة غير الموجودة تُنشأ تلقائيًا.

بعد الاستيراد: لوحة التحكم ← المنتجات للتأكد، وأضف للعلامات الجديدة "أسماء بديلة للبحث" (مثل الاسم بالعربية) من صفحة العلامات التجارية.
