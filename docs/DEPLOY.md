# النشر على الاستضافة — قائمة التحقق

## 1. الاستضافة المقترحة
استضافة تعمل بـ **LiteSpeed** (مثل Hostinger Business أو أي استضافة cPanel/LiteSpeed) مع PHP 8.2+ وMySQL/MariaDB وشهادة SSL مجانية:
- إضافة **LiteSpeed Cache** المجانية تعطي كاش صفحات على مستوى الخادم (مع استثناء السلة والدفع تلقائيًا) — أسرع وأخف من أي إضافة كاش على Apache.
- ملف `.htaccess` الخاص بنا (ضغط، كاش المتصفح، رؤوس الأمان، حظر xmlrpc) متوافق مع LiteSpeed كما هو.
- البديل على Apache/Nginx: WP Rocket (مدفوع، بترخيص باسم العميل).

## 2. نقل الموقع
1. ارفع `public/` (أو ثبّت ووردبريس نظيفًا) وانقل قاعدة البيانات، أو استخدم **UpdraftPlus ← استعادة** من نسخة احتياطية.
2. استبدل الروابط: `wp search-replace 'http://localhost:8080' 'https://الدومين' --all-tables`.
3. في `wp-config.php`:
   ```php
   define( 'WP_ENVIRONMENT_TYPE', 'production' ); // يعطّل ملتقط الإيميلات المحلي ومفاتيح Turnstile التجريبية
   define( 'WP_DEBUG', false );
   define( 'DISALLOW_FILE_EDIT', true );
   define( 'FORCE_SSL_ADMIN', true );
   ```
4. شغّل: `wp eval-file tools/setup/store-setup.php` (آمن للتكرار) ثم `wp nafha reindex`.
5. احذف المنتجات التجريبية عند إضافة المنتجات الحقيقية (الأمر في رأس `tools/setup/demo-products.php`) واحذف الطلبات التجريبية.

## 3. الأمان
- **SSL**: فعّل الشهادة وحوّل كل الروابط إلى HTTPS (الإعدادات ← عام). بعد التأكد أضف رأس HSTS.
- **حساب المدير**: أنشئ مديرًا باسم مستخدم غير `admin` وكلمة مرور قوية، واحذف حساب `admin` المحلي. فعّل التحقق بخطوتين: Wordfence ← Login Security.
- **رابط الدخول**: `https://الدومين/nafha-login/` (و`/wp-admin` يعطي 404 لغير المسجلين).
- **Wordfence**: قفل بعد 5 محاولات فاشلة لمدة 4 ساعات، وقفل فوري لأسماء المستخدمين غير الموجودة. يُفضّل تفعيل *Extended Protection* من لوحة Wordfence ← Firewall بعد النشر.
- **Cloudflare Turnstile**: من dash.cloudflare.com ← Turnstile أنشئ Site Key وSecret للدومين، ثم: الإعدادات ← Cloudflare Turnstile ← أدخل المفاتيح واضغط **Test Response** (الحماية لا تُفعَّل إلا بعد نجاح الاختبار). مفعّلة على: الدخول، التسجيل، استعادة كلمة المرور، المراجعات، دخول/تسجيل ووكومرس — وليست على صفحة الدفع.

## 4. النسخ الاحتياطي
UpdraftPlus مضبوط على: قاعدة البيانات **يوميًا** (آخر 14 نسخة)، والملفات **أسبوعيًا** (آخر 4).
اربط التخزين الخارجي: الإعدادات ← UpdraftPlus ← Settings ← اختر **Google Drive** أو Dropbox ← سجّل الدخول بحساب العميل ← احفظ ← اضغط "Backup Now" للتجربة.

## 5. مدير المتجر
ووكومرس يوفّر دور **مدير المتجر** (Shop Manager): يدير المنتجات والطلبات والكوبونات والتقارير وإعدادات ووكومرس (ومنها تبويب نفحة)، **ولا** يصل للإضافات أو القوالب أو إعدادات الأمان. أنشئ حساب الموظفين بهذا الدور: المستخدمون ← إضافة جديد ← الدور: مدير المتجر.

## 6. بعد النشر
- الإعدادات ← القراءة: تأكد أن "منع محركات البحث من أرشفة هذا الموقع" **غير مفعّل**.
- Google Search Console وGTM وخلاصة المنتجات: انظر [TRACKING.md](TRACKING.md).
- اختبر الأداء على pagespeed.web.dev (الهدف 85+ موبايل).
- حدّث الإضافات والقوالب لآخر إصدار قبل التسليم.
